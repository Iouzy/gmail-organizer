Ligar a tua conta Google

  1. Abre a consola da Google Cloud e cria um projeto.
  2. Em APIs & Services → Library, ativa a Gmail API.
  3. Em Credentials → Create credentials → OAuth client ID, escolhe o tipo Desktop app.
  4. Descarrega o ficheiro JSON e larga-o aqui em baixo.
Larga aqui o ficheiro JSON ou clica para o escolher

O ficheiro fica só no teu computador, ao lado deste programa. Nada é enviado para lado nenhum.

Abre-se uma janela do browser para deres permissão. Volta aqui quando terminares.
